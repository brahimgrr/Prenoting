# Agendav2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a self-contained `/doctor/agendav2` section that merges the current Agenda and Disponibilità sections into one view, feature-complete enough to eventually replace both.

**Architecture:** New `agendaV2()` + `viewAgendaV2()` methods in `DoctorDashboardController` load both schedule data (appointments, slots, timeline rows) and availability modal data (batch form defaults, preview). The view reuses all existing CSS classes and Bootstrap grid — no new CSS. The existing `previewAvailability` and `storeAvailabilityBatch` actions gain a `source=agendav2` / `_source=agendav2` param so the modal flow redirects back to agendav2 instead of `/doctor/availability`.

**Tech Stack:** Laravel Blade, Bootstrap 5 (via existing Vite bundle), PHPUnit Feature tests.

```php
private function viewAgendaV2(Request $request, ?array $availabilityPreview = null): View
{
    $selectedDate = (string) $request->query('date', now()->toDateString());
    $selectedDay  = CarbonImmutable::parse($selectedDate)->startOfDay();
    $currentTime  = CarbonImmutable::now();

    $appointments = Appointment::withPortalRelations()
        ->whereDate('start_at', $selectedDate)
        ->when($request->query('status'), fn ($q, $status) => $q->where('status', $status))
        ->orderBy('start_at')
        ->get();

    $daySlots = AvailabilitySlot::query()
        ->whereDate('start_at', $selectedDate)
        ->orderBy('start_at')
        ->get();

    $timelineItems = $this->buildTimelineItems($appointments, $daySlots);

    $batchForm = $availabilityPreview['input'] ?? [
        'start_date'          => CarbonImmutable::now()->toDateString(),
        'end_date'            => CarbonImmutable::now()->addWeeks(2)->toDateString(),
        'weekdays'            => [1, 2, 3, 4, 5],
        'start_time'          => '09:00',
        'end_time'            => '12:00',
        'slot_duration'       => 30,
        'lunch_break_enabled' => false,
        'lunch_break_start'   => '13:00',
        'lunch_break_end'     => '14:00',
    ];

    return view('doctor.agendav2', [
        'date'                => $selectedDate,
        'appointments'        => $appointments,
        'daySlots'            => $daySlots,
        'agendaRows'          => $this->buildAgendaRows($selectedDay, $timelineItems, $currentTime),
        'currentTime'         => $currentTime,
        'isSelectedToday'     => $selectedDay->toDateString() === $currentTime->toDateString(),
        'fatturato'           => $appointments->sum(fn ($a) => $a->service?->price ?? 0),
        'availabilityPreview' => $availabilityPreview,
        'batchForm'           => $batchForm,
    ]);
}
```

public function previewAvailability(Request $request): View
{
    $validated = $this->validatedBatchAvailability($request);
